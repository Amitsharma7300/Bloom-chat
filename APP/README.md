# Bloomchat mobile app

Expo + React Native app using TypeScript.

## Start developing

1. Install Node.js 22.13 or newer.
2. Run `npm install` if dependencies are not already installed.
3. Run `npm start` and open the project with Expo Go, or use `npm run android` / `npm run ios` with the relevant development tools installed.

The starter screen is in `src/screens/HomeScreen.tsx`.

## Structure

- `src/components` — reusable UI components
- `src/screens` — app screens
- `src/navigation` — navigation setup
- `src/services` — API and external service clients
- `src/hooks` — shared React hooks
- `src/utils` — helper functions
- `src/constants` — app-wide constants and theme values
- `src/types` — shared TypeScript types
- `assets` — images and fonts
- `__tests__` — tests
